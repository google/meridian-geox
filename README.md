# About Meridian GeoX
Meridian GeoX is an open-source solution for measuring cross-publisher
incrementality. By providing publisher-agnostic measurement, it helps close
data gaps and generates ground-truth experiment data used to calibrate
Marketing Mix Models (MMMs). The library offers cost-effective, multi-cell
testing with flexible methodologies. It integrates seamlessly with Meridian to
provide the causal measurement needed to inform MMM priors.
## Key Features
### Unified, Multi-Methodology Framework
Acts as a single library for both study design and incrementality analysis,
supporting multiple state-of-the-art methodologies. This revamped approach
is designed to provide cheaper and more reliable testing.
### Flexible Design & Multi-Cell Capability
Supports all geo experiment types (Holdback, Go-dark, Go-dim, and Heavy-up)
and advanced multi-cell designs (multiple treatment arms against a common
control group).
### Design Comparison
Allows direct comparison of study designs across methodologies and assignment
rules.
### Meridian Integration
Features built-in compatibility with Meridian MMM to suggest GeoX experiments
and convert experiment results into data-driven priors for MMM calibration.
### Ease of Use
Offers a simplified, user-friendly API, robust documentation, data input
templates, and built-in data quality checks.
